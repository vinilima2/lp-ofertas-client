# Instruções do Projeto

### Objetivo:
- Aplicação Web simples que permite que o usuário pesquise produtos que tem interesse em comprar num supermercado
- Permitir criar "Lista de Compras" gravando no localstorage os itens que mais frequentemente compra permitindo ver em quais mercados está mais barato
- É o frontend que consome o Supabase presente em C:\Users\home\Desktop\lp-ofertas
- Interface simples com input para pesquisa e combo com opções de supermercado (Todos, Avenida (avenida), Gigantão (gigantao), Jaú Serve (jau_serve) e Panelão (panelao)

### Regras
- Aplicação simples com HTML / CSS / JS
- CSS com animações e com identidade própria, sem copiar muitas coisas
- Conexão com Supabase apenas para consultas
- Permitir limpar a lista de compras, adicionar e remover itens
- Incluir ícones bonitos
- Pensar em layout preferencialmente mobile mas que funciona no desktop também
